# 定论（跨任务长期有效）

## 定论（已否决 / 已解决 · 勿重开）
- PWM_DT_SRC = 已解决: 单路PWM同接HIN与LIN#→驱动出互补+死区，MCU DTG=0  依据: 实测20kHz/50%  日期: 2026-10-23  来源: 你
- PA7_USE = 已解决: 本轮不配置，仅作备用（死区不足时走 TIM1_CH1N 重映射）  依据: 用户说明+实测仅CH7有波  日期: 2026-10-23  来源: 你
- ADC_PATH = 已解决: ADC 通路正常（3.3V 注入 -> raw 4095 / Vpin 3299mV）  依据: 实测  日期: 2026-10-23  来源: 实测
- ADC_I_FLOAT = 已解决: 未加电时电流通道读数无效（运放无供电，注入经 ESD 倒灌带偏）  依据: 1265->2905  日期: 2026-10-23  来源: 实测
- ADC_CH2_OK = 已解决: 通道2(PA1)同样正常（3.3V -> raw 4095），两路 ADC 均已验证  依据: 实测  日期: 2026-10-23  来源: 实测
- RTT_REREAD = 已解决: RTT 连续第二次读常空输出，先 jlink reset 再读必恢复  依据: 3 次实测  日期: 2026-10-23  来源: 实测
- ADC_TCONV = 已解决: 转换时间不可直测（无 EOC/触发输出脚），改用可持续率给上界  依据: 实测  日期: 2026-10-24  来源: 实测
- ADC_CNDTR = 否决: CNDTR 计数法测转换时间不可靠（>16kHz 读数离散），弃用  依据: 实测  日期: 2026-10-24  来源: 实测
- SWD_LOST_RECOVER = 已解决: DAP 失联只能断电重启（4 线 SWD 无 NRST，reset 无效）  依据: 实测  日期: 2026-10-29  来源: 实测
- EG2131_NO_SHOOT = 已解决: 闭锁+250ns 内置死区 → 输出不可能同时导通，"80% 直通"判断撤回  依据: 手册V1.0  日期: 2026-10-30  来源: 手册
- PWM_INVERTER = 否决: 互补对+BJT 反相器方案（慢沿 2~3µs→驱动输入长时间在不确定区→热失控），改双通道  依据: 实测  日期: 2026-10-30  来源: 实测
- PWM_DT_220_FALSE = 已解决: DT≥220 才不发烫是 CCR2 bug 伪象；定 36 计数  依据: 示波器两沿+输入电流  日期: 2026-11-08  来源: 实测
- PWM_TOPO_SINGLE = 定论: 单输入同相同宽，249ns 死区全交 EG2131  依据: 栅极+输入电流  日期: 2026-11-08  来源: 你+实测
- PWM_SHOOT_ROOT = 已解决: R10(HO 栅阻)4.7Ω 关断慢于死区致重叠；改 0Ω，R2 保持  依据: 你实测  日期: 2026-11-08  来源: 你
- PWM_STOP_MUST_ZERO = 约定: 停机必须 CCR1=CCR2=0（DRV_PWM_Stop），不压到下限  依据: 你  日期: 2026-11-04  来源: 你
- STARTUP_WINDUP = 已解决: 无输入 PI 顶到 CCR1=3020；NOIN_GUARD 解决  依据: 断电实测  日期: 2026-11-04  来源: 实测
- ISR_HOME = 约定: 中断回调统一写 stm32f1xx_it.c；驱动只暴露 XXX_ConvCpltIsr()  依据: 你  日期: 2026-11-05  来源: 你
- ISR_FLOW = 定论: it.c 回调 DRV_ADC_ConvCpltIsr()→APP_CONTROL_Step()  依据:2kHz  日期: 2026-11-05  来源: 你+实测
- BOOT_OUTPUT_OFF = 约定: 上电/烧录后停波、档位 5V；Key1 开启先出 5V，关机即回 5V 档  依据: 用户  日期: 2026-11-06  来源: 你
- CTRL_DN_TRANS = 已解决: 降压恒流过渡+iref 限速 → 12→5V 由 −33% 到 −0.2%  依据: RTT  日期: 2026-11-06  来源: 实测
- NOIN_GUARD = 已解决: CCR1≥MIN 且 Vout<800mV 50ms → 停波，200ms 后低目标探测  依据: 实测  日期: 2026-11-05  来源: 实测
- OVP_RETRY_LIMIT = 已解决: 空载冲压 17V 致 OVP 无限重启；5s 内 >3 次即关机显 NO LOAD  依据: RTT  日期: 2026-11-08  来源: 实测
- KEY2_WHILE_OFF = 定论: Key2 关机也改 SET；Key1 开启按 SET 输出  依据: 12V 实测  日期: 2026-11-08  来源: 实测
- OLED_SSD1306 = 定论: 128x64 I2C 0x3C，4 行 8x16，5Hz，旋转 180°(A0/C0)  依据: 实测  日期: 2026-11-08  来源: 实测
