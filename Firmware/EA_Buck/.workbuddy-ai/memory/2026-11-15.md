## 示波器实测：4 档软启动 / 关断 / 纹波 + 测试报告

**任务**：用 Siglent SDS824X HD 测 3.3/5/9/12V 四档的上升沿、下降沿、纹波，出报告。
条件：24V 输入，10Ω 阻性负载，CH1 10× DC。

### 结果
- 纹波（20M 限带主带）：15.0 / 15.8 / 7.5 / 15.1 mV，纹波系数 0.08–0.46%
- 上升时间 10–90%：19.6 / 24.4 / 35.6 / 44.4 ms；超调 12.87 / 8.55 / 5.88 / 4.42%
- 下降时间：0.08–0.21 ms；负向过冲 −2.29 / −2.51 / −4.90 / −4.32 V；振铃 735–793 Hz（LC 理论 723 Hz）

### 关键技术坑（已写 .cl/memory/conclusions.md）
1. **`:TRIGger:EDGE:LEVel` 是绝对电压**，与通道 offset 无关。embeddedskills `scope_transient` 用
   `level_abs - voff` 换算，offset≠0 时会把电平推到信号外 → 永不触发（status 停在 Ready、空帧）。
   自写 `configure_v2()` 直接写绝对电平解决。
2. **GDB `call` 在本工程不可用**：10 kHz ADC ISR 会与 GDB 的 call 抢栈 → HardFault。
   改用 `set var s_output_on / s_vref_mv / s_vref_target_mv` 写内存（不执行代码）+ `monitor go`。
3. **JLink Commander 的 connect 会粘滞 halt**：退出后 CPU 停在 `__main`，表现为"输出设置了但不爬升"。
   GDB 操作后必须 `monitor go`（PC=0xdeadbeee 即运行态），异常用 `jlink_exec.py reset` 兜底。
4. 下降沿负压读数需**扩大负向量程**再测，否则底部削顶使 undershoot 虚高且随量程漂移。
   已复核原始波形：负压区持续约 1ms、95+ 采样点低于 −1V，非单点伪影。

## 更正：上面"纹波劣化 3.5–8 倍"的结论作废

根因是**测错了对象**：`rtt_send.py` 里 import 了不存在的符号（`from jlink_rtt import RTTClient`），
subprocess 报 ImportError 但未检查返回码，脚本照旧打印 "RTT sent" → `V3300`/`ON` 从未送达板子；
同时更早的 JLink Commander 已把 CPU halt 住 → PWM 停 → 输出 0 V。
AC 耦合测 0 V 静止信号，得到的是**噪声底**（实测 13–17 mV，与原报告 9.7–28.2 mV 同量级）。

**没有电容劣化**，也没有有效的"劣化前"基线。真实纹波见下。
