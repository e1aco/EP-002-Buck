# 项目状态 (State) — AI 维护，状态单源
> **模板维护**：本文件所有 `>` 引导行是**格式规范**，AI 生成/更新时**原样保留**；AI 只维护 `>` 之外的正文（表格行、任务条目）。
> **单源声明**：任务 / 风险 / 时序在此；`.cl/require.md` 只放**稳定需求**（硬件池/引脚/调试回传）。
> **变化率=高频**：`/cl gon` 只读本文件 + `.cl/memory/`（不整读 require）。
> **两区**：**一、待办与风险**（未完成 / 待测 / 未决）· **二、已完成**（滚动窗口）。
> **更新时机**：`/cl init` 建骨架；`/cl run`「任务验收段」每任务迁移+轻归档（标 `[✓]`/`[x]`、依据、定论/常量升 memory、**两区滚动**、commit）；`/cl run`「会话收尾段」重归档（风险剥入 memory 定论 / memory 时效·体积门 / 产物清理）；`/cl code` 标 `[c]` 及你确认后迁移；`/cl tim` 回填时序。
